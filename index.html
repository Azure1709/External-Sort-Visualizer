❓ External Sort là gì?

External Sort (Sắp xếp ngoại) là thuật toán sắp xếp dữ liệu lớn hơn bộ nhớ RAM. Dữ liệu được chia thành các Run nhỏ, sắp xếp trong RAM, rồi gộp lại bằng K-Way Merge.

⚙️ Cách hoạt động

🔹 Phase 1: Tạo Run

  1. Đọc M phần tử từ file vào RAM
  2. Sắp xếp M phần tử đó
  3. Ghi ra đĩa thành 1 Run
  4. Lặp lại cho đến hết file

🔹 Phase 2: K-Way Merge

  1. Lấy K Run đầu tiên
  2. So sánh phần tử đầu mỗi Run bằng Min-Heap
  3. Chọn phần tử nhỏ nhất → Ghi ra Output
  4. Lặp lại đến khi còn 1 Run duy nhất
📊 Độ phức tạp

Thời gian: O(N × log N)

Bộ nhớ: O(M) — M phần tử trong RAM

I/O: O(N/B × logK(N/M))

💡 Ví dụ & Trường hợp đặc biệt

📝 Ví dụ minh họa:

Cho dữ liệu: [15, 42, 7, 23, 31, 4, 18, 56, 12, 9]

Với M = 5 và K = 2:

  • Run 1: [15,42,7,23,31] → sắp xếp → [7,15,23,31,42]
  • Run 2: [4,18,56,12,9] → sắp xếp → [4,9,12,18,56]
  • Merge Run 1 & 2 → [4,7,9,12,15,18,23,31,42,56] ✅

⚠️ Trường hợp đặc biệt:

  • Dữ liệu đã sắp xếp: Vẫn tạo Run nhưng merge nhanh hơn
  • Dữ liệu giảm dần: Worst case cho Insertion Sort
  • Số phần tử < M: Chỉ cần 1 Run, không cần merge
  • Tất cả phần tử giống nhau: Ổn định, giữ thứ tự

💡 Mẹo sử dụng:

  • M càng lớn → Ít Run hơn → Merge nhanh hơn
  • K càng lớn → Merge nhiều Run cùng lúc → Ít pass hơn
  • Dữ liệu nhỏ (< 50 phần tử): Dễ quan sát từng bước
