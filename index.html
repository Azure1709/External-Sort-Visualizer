⚙️ Nguyên lý hoạt động

1. Phân chia: Đọc từng phần dữ liệu vừa RAM, tạo Run riêng biệt

2. Sắp xếp: Mỗi Run được sắp xếp trong RAM bằng QuickSort

3. Trộn K-Way: Lấy K runs, so sánh phần tử đầu, chọn nhỏ nhất
